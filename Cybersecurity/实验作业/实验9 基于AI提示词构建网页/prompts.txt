福州大学主页实验 Prompt 记录

阶段一：页面结构

Prompt 1：我刚开始学习 HTML，想先搭一个福州大学主页的基本框架。页面大概需要顶部导航、校园简介、校园动态、留言板和页脚这几个部分。能不能先教我这些区域应该怎么安排，不用一下子写完所有代码？

Prompt 2：我已经写了一点页面结构，想给顶部加一个福州大学 Logo 和三个导航链接，分别跳到校园简介、校园动态和留言板。请帮我看看应该写哪些标签和链接，尽量只改导航这一小部分。

Prompt 3：请帮我把校园简介、校园动态和留言板的内容补充得更像一个真实的大学主页。校园简介放校园图片和学校历史，校园动态放几条通知，留言板放昵称、留言内容和提交按钮。可以先给我一个简单的写法并解释一下。

阶段二：页面样式

Prompt 4：我想让这个福州大学主页看起来比较安静、整洁，不要太花哨。能不能教我用深蓝色、砖红色、米白色和一点黄色来做配色，并把标题、正文和按钮的基本样式写出来？

Prompt 5：我有一张叫 `campus-hero.jpg` 的校园照片，想把它放在首页最上面的背景位置，图片上面显示“明德至诚，博学远志”和两个按钮。请帮我调整这一块的 CSS，让文字看得清楚，代码不用涉及其他区域。

Prompt 6：现在校园简介和留言板在电脑上显示得还可以，但手机上可能会挤在一起。请教我怎么用 CSS Grid 和媒体查询，让电脑端显示两栏、手机端改成一栏，并且图片、表单和按钮不要超出屏幕。

Prompt 7：页面的基本颜色已经定下来了，但按钮、信息卡片和输入框看起来还比较普通。能不能帮我调整一下边框、间距、悬停效果和键盘选中时的样式，让页面更清楚、更容易使用？

阶段三：留言板功能

Prompt 8：我想让留言板真正可以使用。请教我如何监听表单提交，读取昵称和留言内容，判断输入框是不是空的，然后把新的留言显示到右侧列表里。希望你分步骤说明，不要直接替换整个网页。

Prompt 9：留言显示出来以后，刷新网页就没有了。请帮我在现在的代码上加一个简单的 `localStorage` 保存功能，让留言刷新后还能保留；如果读取到的数据不对，希望页面仍然可以正常打开。

Prompt 10：请帮我把留言显示部分整理一下：每次提交后重新显示留言，最新留言放在前面；如果还没有留言，就显示一段提示文字。用户输入的内容应该安全地显示，不能影响页面结构。

Prompt 11：请帮我检查留言板的最后一部分代码，看看用户输入应该怎样安全地放进页面，提交成功后如何清空输入框并显示“留言已提交”，以及页面刚打开时没有留言应该显示什么提示。只告诉我需要修改的地方和原因。
