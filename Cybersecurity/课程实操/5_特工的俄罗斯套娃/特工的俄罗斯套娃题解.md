# 特工的俄罗斯套娃 题解

## 题目考点

- JPG 文件结构识别
- 文件尾部追加数据检查
- ZIP 压缩包文件头识别
- 加密 ZIP 弱口令爆破
- 从压缩包中提取 `secret.txt` 并读取 token

## 解题思路

题目给出的 `final_image.jpg` 可以正常打开，但提示中说明“文件尾部却比画面本身更值得检查”，因此需要检查图片文件结构，而不是只关注图片显示内容。

首先查看 JPG 文件尾部，可以发现 JPG 正常结束标记 `FF D9` 后面仍然存在额外数据，并且紧接着出现了 ZIP 文件头：

```text
PK 03 04
```

这说明图片尾部追加了一个 ZIP 压缩包。

可以直接使用 `zipinfo` 或 `unzip` 识别该图片中的 ZIP 内容，发现其中包含一个文件：

```text
secret.txt
```

但该 ZIP 被口令加密，需要使用题目提供的小字典 `weak-passwords.txt` 进行尝试。

字典内容为：

```text
123456
654321
111111
888888
000000
520131
```

逐个尝试解压后，发现正确口令为：

```text
111111
```

使用该口令解压并读取 `secret.txt`，即可得到 token。

示例命令如下：

```bash
zipinfo final_image.jpg
```

```bash
while IFS= read -r p; do
  out=$(unzip -p -P "$p" final_image.jpg secret.txt 2>/dev/null)
  if [ -n "$out" ]; then
    echo "PASSWORD=$p"
    echo "$out"
    break
  fi
done < weak-passwords.txt
```

输出结果：

```text
PASSWORD=111111
NEST-K5RUJNPEA46P32YPTN6LFAHYMEDU
```

## 最终输出的 flag

```text
NEST-K5RUJNPEA46P32YPTN6LFAHYMEDU
```
