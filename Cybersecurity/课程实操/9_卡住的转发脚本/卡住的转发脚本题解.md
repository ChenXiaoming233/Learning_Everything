# 卡住的转发脚本题解

## 题目考点

本题主要考察 Web 接口调用流程的修复能力，而不是密码破解、JWT 伪造或身份系统攻击。核心考点包括：

1. 会话复用

   服务端通过会话状态记录事件流程，因此需要在 `bootstrap`、`events/next`、`upstream`、`claim` 之间复用同一个 HTTP 会话，保持 Cookie 一致。

2. 请求方法

   `/api/bootstrap` 接口要求使用 `POST`，原始脚本错误地使用了 `GET`。

3. payload 字段修复

   `config.json` 中给出了字段转换规则：

   ```json
   {
     "target_path": "payload.route",
     "operation": "prefix",
     "prefix": "fzy5figc-",
     "required_field": "payload.reviewed",
     "required_value": true
   }
   ```

   因此每个事件需要将 `payload.route` 加上指定前缀，并设置 `payload.reviewed` 为 `true`。

4. 可恢复错误重试

   `/api/upstream` 可能返回 `503`，如果响应中包含 `retryable=true`，表示当前事件可以恢复，应当重试同一个事件，而不是跳过当前循环去消费下一个事件。

5. 合法 JSON 输出

   最终需要将三个事件返回的 `receipt` 列表写入合法的 `result.json`，再提交到 `/api/claim`。

## 解题思路

首先访问题目环境首页：

```text
http://web-b773c64916.adworld.xctf.org.cn:80/
```

页面给出了下载地址和接口说明：

```text
POST /api/bootstrap
GET  /api/events/next
POST /api/upstream
POST /api/claim
```

下载 `starter.py` 与 `config.json` 后，原始脚本中存在四类问题：

```python
requests.get(base + "/api/bootstrap", json={})
```

这里应使用 `POST`，并且后续请求都必须复用同一个会话。

原脚本还错误修改了字段：

```python
event["payload"]["user"] = "wrong-field"
```

根据 `config.json`，真正需要修改的是：

```python
event["payload"]["route"] = "fzy5figc-" + event["payload"]["route"]
event["payload"]["reviewed"] = True
```

提交 `/api/upstream` 时，事件需要保留外层字段，并以如下结构提交：

```json
{
  "event": {
    "sequence": 1,
    "event_id": "...",
    "nonce": "...",
    "payload": {
      "route": "fzy5figc-login",
      "method": "POST",
      "operator": "node-01",
      "reviewed": true
    }
  }
}
```

同时，遇到可恢复的 `503` 时，需要重试当前事件：

```python
while True:
    response = session.post(base + "/api/upstream", json={"event": event})
    if response.status_code == 503 and response.json().get("retryable") is True:
        continue
    response.raise_for_status()
    receipts.append(response.json()["receipt"])
    break
```

完成三个事件后，将 receipt 列表写入 `result.json`：

```json
[
  "rcpt-1-575b2ee4c25dec9230516c2b",
  "rcpt-2-cfa78efb592a7ebe7ac2fa2c",
  "rcpt-3-f903f7540a6f32ab6957b925"
]
```

最后向 `/api/claim` 提交：

```json
{
  "receipts": [
    "rcpt-1-575b2ee4c25dec9230516c2b",
    "rcpt-2-cfa78efb592a7ebe7ac2fa2c",
    "rcpt-3-f903f7540a6f32ab6957b925"
  ]
}
```

服务端返回：

```json
{
  "ok": true,
  "flag": "flag{YgpoLanuIsaPfXpUn80w8X1FOgT4OPPl}"
}
```
