# Alient [7PT] [OSINT] 题解

## 题目考点

本题是一道基于图片地理定位的 OSINT 题，主要考查以下能力：

1. 从网页中获取朋友圈原图，而不是仅分析压缩后的缩略图；
2. 从朋友圈文字中提取省份、时间和行为描述等显式线索；
3. 识别城市天际线、标志性建筑、历史街区风貌和地形特征；
4. 使用图片识别、搜索引擎和在线地图进行交叉验证；
5. 区分照片中的远景地标、实际拍摄点和题目要求提交的住宅区；
6. 根据建筑之间的相对位置和拍摄方向完成反向地理定位。

本题最容易出现的误区，是识别出照片中的知名建筑后直接提交该建筑或景区名称。题目真正询问的是目标停留地点“面前脚下的住宅区”，因此还需要继续反推拍摄点附近的住宅项目。

## 解题思路

进入题目环境后，打开密件中的“朋友圈”页面。页面中有三张仍可查看的照片，对应的原图资源为：

```text
/assets/2.jpg
/assets/4.jpg
/assets/5.jpg
```

应先下载原图，以便观察远处建筑轮廓、灯光、招牌和近处环境。

### 1. 提取文字线索

第二条朋友圈中写道：

> 下班路过这里，这两天福建风很大。

这句话直接将搜索范围缩小到福建省。

最新一条朋友圈则写道：

> 在这里坐到天快黑……最后还是揉成团丢下去了。

结合密件中“把一段信息留在了面前脚下的住宅区”的描述，可以判断目标是在一处较高位置停留，并将纸条丢向前方或坡下的住宅区。

### 2. 分析三张原图

`2.jpg` 展示了完整的城市夜景。画面中可以看到：

- 大型临江欧式建筑群；
- 带塔楼和轮廓灯的建筑；
- 后方密集的高层住宅天际线；
- 前景中的老式坡屋顶和树木。

`4.jpg` 与 `2.jpg` 拍摄于基本相同的位置，但镜头更低，能够看到更多近处屋顶、树木、道路和河岸建筑。这张图片最适合判断拍摄点与前方住宅区的空间关系。

`5.jpg` 展示了高大挡墙、榕树根系和坡地绿化。该图不能单独确定住宅区，但符合福建南方城市历史街区、山坡公园和老建筑周边的环境特征，可作为辅助证据。

### 3. 识别远景地标

以图片中最显眼的欧式临江建筑群为目标，可以使用图片识别或组合关键词搜索：

```text
福建 欧式建筑群 夜景 江边
福州 欧式建筑 夜景 双塔
福州 中洲岛 夜景
福州 烟台山 中洲岛 视角
```

搜索和图片对比结果表明，画面中的大型欧式建筑群是福州中洲岛。其判断依据包括：

1. 建筑位于水边，具有连续的欧式立面和多座塔楼；
2. 建筑夜间灯光轮廓与中洲岛公开照片一致；
3. 周围高层住宅的分布与福州中心城区天际线相符；
4. 前景中的老建筑和坡地环境符合烟台山历史风貌区。

由此可将照片定位到福州烟台山一带，镜头大致朝向中洲岛及闽江北岸。

### 4. 反推拍摄位置

识别中洲岛后，继续比较两张夜景照片中的空间关系：

- 拍摄位置明显高于周边道路和建筑；
- 前景先出现树木和老式瓦屋顶，之后才是中洲岛；
- 中洲岛位于拍摄点北侧，因此拍摄点应在闽江南岸；
- 烟台山正好具有山坡地形、历史建筑和面向中洲岛的高处视野。

因此，照片中的中洲岛只是用于确定方向的远景地标，目标真正停留的位置位于烟台山仓前片区。

### 5. 定位住宅区

在地图中同时搜索烟台山、中洲岛和仓前路，并沿照片视线检查烟台山高处前方、坡下的住宅项目。再将地图位置、楼盘实景和照片中的建筑相对方向进行交叉比对，可以确定题目要求的住宅区是：

```text
万科仓前九里
```

“仓前”与烟台山所在的仓前片区对应，该住宅区的位置也符合题目所说的“面前脚下”。

提交时按照题目要求，只填写住宅区名称，不添加“福州”“仓山区”等城市或行政区信息。

提交以下答案：

万科仓前九里
