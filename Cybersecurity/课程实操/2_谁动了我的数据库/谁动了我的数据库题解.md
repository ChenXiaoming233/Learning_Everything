# 谁动了我的数据库 题解

## 一、题目考点

- **pcapng 流量包取证**：识别附件类型，分析网络流量中的 HTTP、MySQL 等协议内容。
- **phpMyAdmin 操作流量分析**：从 Web 请求和 Cookie、路径、参数中判断用户正在通过 phpMyAdmin 操作数据库。
- **MySQL 明文协议分析**：从 3306 端口流量中还原数据库连接、查询语句和结果。
- **SQL 操作定位**：重点关注 `CREATE TABLE`、`INSERT INTO`、`SELECT`、`SHOW TABLES` 等语句。
- **编码识别与解码**：识别疑似 Base64 编码字符串，并解码得到最终 flag。
- **干扰项排除**：题目中存在 `false_flag` 表，需要结合真实 SQL 操作链路判断有效线索。

## 二、解题思路

附件位于：

```text
2022zn04/ezsql.pcapng
```

首先确认附件类型：

```bash
file 2022zn04/ezsql.pcapng
```

可以确认这是一个 `pcapng` 流量包。

由于题目名称为“谁动了我的数据库”，优先关注数据库相关流量。使用 `strings` 查看可读内容时，可以发现大量 phpMyAdmin 相关 HTTP 内容，例如：

```text
GET /index.php HTTP/1.1
Host: 192.168.3.195:800
phpMyAdmin
```

这说明用户很可能通过 phpMyAdmin 操作了数据库。

继续分析流量，可以看到访问的数据库名为：

```text
security
```

同时，在 MySQL 流量中可以看到多个表名，例如：

```text
emails
false_flag
referers
uagents
users
lookme
```

其中 `false_flag` 很像干扰项，不能直接作为最终答案。继续追踪后续 SQL 操作，发现攻击者创建并操作了 `lookme` 表。

关键 SQL 语句如下：

```sql
CREATE TABLE `security`.`lookme` (
  `your_like` VARCHAR(50) NOT NULL
) ENGINE = MyISAM;
```

之后出现了一条关键插入语句：

```sql
INSERT INTO `lookme` (`your_like`)
VALUES ('ZmxhZ3s5OWE3ZTMxNS1iMmE3LTRhMjUtODhhYy04Y2VkODY1NGNlZTh9');
```

字段值：

```text
ZmxhZ3s5OWE3ZTMxNS1iMmE3LTRhMjUtODhhYy04Y2VkODY1NGNlZTh9
```

符合 Base64 编码特征。对其进行 Base64 解码：

```bash
echo 'ZmxhZ3s5OWE3ZTMxNS1iMmE3LTRhMjUtODhhYy04Y2VkODY1NGNlZTh9' | base64 -d
```

得到：

```text
flag{99a7e315-b2a7-4a25-88ac-8ced8654cee8}
```

因此，本题真正的 flag 并不在 `false_flag` 表中，而是藏在后来插入到 `lookme.your_like` 字段中的 Base64 字符串里。

## 三、最终输出的 flag

```text
flag{99a7e315-b2a7-4a25-88ac-8ced8654cee8}
```
