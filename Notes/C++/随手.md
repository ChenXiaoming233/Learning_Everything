读入整行：(PAT Basic 1052, 1009) 

`getline(std::istream& is, std::string& str, char delim = '\n');`第一个参数为输入流，常见为 `cin` 从输入流读入 / `(数据流名)`从数据流读入 / `istringstream` 从字符串读入；第二个参数为读取内容存放的位置；第三个参数为分隔符，提示读取停止，默认为换行符 `\n`。

函数在读取后会 **丢弃分隔符**，下次读取可以从下一行开始。

函数会在每次循环中从上一次读取结束的位置继续读取，直到缓冲区清空。

**坑**：在使用 `cin >>` 读取一行后，其读入指针停留在该行的末尾，紧接着使用`getline()` **会读到一个空行**，需要手动清掉缓冲区。

```c++
string s = "42,3.14,C++";
stringstream ss(s);
string part;

while (getline(ss, part, ','))
    cout << part << endl;
```

若需要保留分隔符，可以使用 get() 构造一个 getline():

```cpp
string part;
char c;

while (ss.get(c)) {
    part.push_back(c);
    if (c == ',') break;    // 分隔符也保留
}
```



拆字读入：

`int = ss.get(char &ch);`参数为读取内容存放的位置

函数从流中读取一个字符，以 **`int`** 类型返回该字符的 **ASCII 值**；如果读取失败或到达文件末尾，则返回 `EOF(-1)`

函数在读取后 **不会丢弃分隔符**。

函数会在每次循环中从上一次读取结束的位置继续读取，直到缓冲区清空。

```c++
stringstream ss("hello");
int ch;
while (ss.get(ch)) {
    cout << "读取字符：" << static_cast<char>(ch) << endl;
    cout << "ASCII值是：" << ch << endl;
}
```

类型匹配判定：(PAT Basic 1054, 1009)

```c++
// ss.fail() 检测输入流状态是否失败
// 类型不匹配
stringstream ss("abc");
int x;
ss >> x;          // 试图把 "abc" 转成 int
cout << ss.fail(); // 输出：1 (true)
// 到达文件末尾或流为空
stringstream ss("");
ss >> x;          // 没有数据可读
cout << ss.fail(); // 输出：1 (true)

// ss.clear() 清除流的错误状态
ss.clear();
cout << ss.fail(); // 输出：0 (false)
```
