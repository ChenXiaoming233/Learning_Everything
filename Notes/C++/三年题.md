# 🧭 **总体分类框架**

三年试卷的题目主要可以分成以下大类：

1. **基础模拟 / 字符串处理类**
2. **数组 / 双指针 / 滑动窗口 / 前缀和类**
3. **链表题（结构体操作）**
4. **排序 / 自定义排序**
5. **数学 / 快速幂 / 数论 / 质因数分解**
6. **DFS / BFS / 图搜索 / 拓扑与可达性判断类**
7. **贪心 / 排序 + 贪心策略题**
8. **栈 / 解析表达式 / 数据结构模拟**
9. **浮点数二分 / 数值方法类**
10. **综合性逻辑 / 思维题**

接下来逐类整理。

------

# 🌱 **一、基础模拟 / 字符串处理（从易到难）**

这一类通常代码量不大，逻辑清晰度决定得分。

### **最简单 → 略复杂**

**①（简单）2024 - 7. 无聊的游戏**
 判断每轮谁大、统计胜场，无算法难度。

**②（简单）2024 - 8. 字母串处理（CF 118A）**
 删元音、转小写、前加 '.'，简单字符串遍历。

**③（简单）2024 - 10. 绝对值比大小**
 按绝对值排序、绝对值相同按原值小的排前。

👀 **④（简单但略长）2023 - 1. L1-059 敲笨钟（PTA）**
 按拼音判断“ong”韵，拼接句子，纯模拟。

✅ **⑤（中等）2023 - 5. PTA 小明打字**
 模拟 Home/End/左右/Insert/Backspace 操作，
 需要用链表或双端队列维护光标，代码较长。



------

# 📐 **二、数组 / 最大子段和 / 区间类**

### **难度从低到高：**

❗✍️ **①（简单）2024 - 2. 最大子列和（LeetCode 53）**
 标准 Kadane，经典基础题。

**②（中等）2022 - 6. 讨厌的数**
 倒序删除出现的数字，细节处理。

❗✍ **③（中等偏上）2022 - 5. 区间最小数 × 区间和（单调栈 + 前缀和）**
 典型“最大化 min × sum”，难度明显提升。

------

# 🪢 **三、链表相关**

### **由易到难：**

❗**①（中等）2024 - 3. 重排链表（L2-022）**
 找中点、反转、合并，链表综合性小题。

------

# 🔧 **四、排序 / 自定义规则**

排序本身简单，关键是规则设计。

**①（简单）2024 - 10. 绝对值比大小（已归类）**
 本质是排序规则题。

✍ 数学 - 质因数分解 **②（简单）2023 - 7. XTU-OJ 1089 质因数分解**
 质因数输出时按顺序，稍有技巧但不难。

------

# 🔢 **五、数学 / 数论 / 快速幂**

❗✍ 数学 - 快速幂 - **①（简单）2024 - 1. A 的 B 次方的后四位（UESTC-167）**
 快速幂的基础版，只取后四位。

✍ 数学 - 质因数分解 - **②（中等）2023 - 7. 质因数分解（重复）**
 常规数论。

------

# 🧭 **六、DFS / BFS / 图搜索 / 可达性 / 渗透类**

这一类是大题里最常考的核心算法。

### **难度从低到高：**

**①（中等）2024 - 5. 淹没岛屿（洛谷 P8662）**
 网格 DFS，判断“完全淹没”的岛屿数量。

**②（中等偏上）2024 - 6. 引水入城（洛谷 P1514）**
 本质是：
 第一行 = 水源
 能否逐层往低处传递水利设施？
 需要方向判断 + 图可达性，带一定思维量。

------

# 🎯 **七、贪心 / 策略类**

❗**①（中等）2023 - 6. 1020 月饼（PTA）**
 按单价排序、贪心卖月饼。

❗**②（中等偏上）2024 - 9. 鱼与熊掌（GPLT L2-1）**
 双物品统计共同拥有的人数，矩阵统计类问题。

------

# 🗃️ **八、栈 / 解析表达式 / 数据结构模拟**

**①（简单—中等）2023 - 3. 求化学式分子量**
 需要栈处理括号、乘法。

**②（中等）2022 - 2. 化学分子质量计算（无嵌套括号）**
 比 2023 难度稍低，但本质类似。

------

# 🌡️ **九、浮点二分求方程（数值方法）**

两年重复考。

❗**①（中等）2023 - 2. 求解四次方程组**
 **②（中等）2022 - 8. 解方程**
 都是浮点二分，但题目形式略不同。

------

# 🧩 **十、综合逻辑题 / 思维题**

这一类往往没有固定算法，而是考“是否理解问题结构”。

### **难度由低到高：**

✅ **①（简单）2024 - 7. 无聊的游戏**
 简单逻辑。

**②（中等偏上）2024 - 4. 兔子试毒（腾讯）**
 经典二进制标号问题，
 解法是：`所需兔子数 = ceil(log2(1000)) = 10`。

⚠ **③（中等）2022 - 3. 购票插队问题**
 队列维护 + 怒气清零，稍微复杂的模拟。

⚠ **④（中等偏上）2023 - 4. Prince and Princess（ICPC 2019）**
 人与真假信息的逻辑推理，难度在整体三年卷中偏高。
